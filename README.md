# AdventureGear - Outdoor Equipment E-Commerce

A modern, responsive e-commerce website for outdoor adventure equipment built with React and Vite.

## Features

- 🏕️ **Outdoor Adventure Theme** - Specialized in camping, hiking, and adventure gear
- 📱 **Responsive Design** - Works perfectly on mobile, tablet, and desktop
- 🛒 **Full Shopping Cart** - Add, remove, and update quantities
- 🔍 **Product Search & Filter** - Find gear by category, price, and more
- 💳 **Checkout Process** - Multi-step checkout with form validation
- ⚡ **Fast Performance** - Built with Vite for optimal speed
- 🎨 **Modern UI/UX** - Clean, adventure-themed design

## Tech Stack

- **React** - Frontend library
- **Vite** - Build tool and dev server
- **React Router** - Page navigation
- **React Icons** - Icon library
- **CSS Modules** - Styling
